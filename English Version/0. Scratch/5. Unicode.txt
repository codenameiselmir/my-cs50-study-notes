ASCII gave computers a standard way to represent text using numbers.

For example:

A -> 65
B -> 66
a -> 97

This worked well for basic English text, but there was an obvious problem.

The world contains far more characters than ASCII can represent.

Different languages use:

- accented characters;
- different alphabets;
- different writing systems;
- thousands of unique symbols;
- mathematical symbols;
- currency symbols;
- emojis;
- and many other characters.

ASCII simply did not have enough possible values to represent all of them.

# WHAT IS UNICODE?

Unicode is a universal standard for representing text.

Its goal is to assign a unique number to characters from writing systems around
the world.

This includes:

- Latin characters;
- Arabic characters;
- Chinese characters;
- emojis;
- and much more.

Instead of different computers inventing their own numbers for characters,
Unicode provides a shared international standard.

The basic idea is similar to ASCII: Character -> Number

But Unicode supports a vastly larger collection of characters.

# CODE POINTS

In Unicode, every character is assigned a unique number. This number is called a code point.

- A → U+0041
- B → U+0042
- a → U+0061
- ş → U+015F
- € → U+20AC

The U+ prefix simply means: “This number is a Unicode code point.”

When Unicode was designed, the original numeric values of ASCII characters were intentionally 
preserved. Because of this, ASCII characters still have the same values within Unicode.

In other words, ASCII can be considered a subset of Unicode.
